# Contributing

Thanks for contributing to Fashion Store.

## Development Setup

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Create `.env.local` from `.env.example`.
4. Run the development server with `npm run dev`.

## Before Committing

Run:

```bash
npm run lint
npm run build
```

Make sure the project builds successfully and that no secrets or local environment files are included.

## Commit Messages

Use short, descriptive commit messages, for example:

```text
Add product search
Fix cart state synchronization
Improve checkout validation
Update responsive navbar
```

## Pull Requests

When opening a pull request:

- Explain what changed.
- Mention any related issue.
- Include screenshots for UI changes when useful.
- Keep unrelated changes out of the same pull request.
